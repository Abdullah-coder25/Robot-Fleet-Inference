Sources and assumptions
  • Cosmos prices and billing: Cosmos3 Nano Sim Bimanual and Nano Sim Transfer are each $0.102 per minute of session time, metered per second while the GPU is reserved, including idle time between commands. Bimanual docs, Transfer docs.
  • What each model does: Bimanual generates video from arm poses and grips; it predicts visual evolution rather than running physics, so it gives no simulator state or task-success score, and the hosted checkpoint supports only the AgiBot embodiment. Transfer turns simulator depth frames into realistic video; the simulator still controls motion, physics and success criteria. Same two pages.
  • Real-robot evaluation effort: the AutoEval study (Zhou et al., UC Berkeley) reports that evaluating OpenVLA took more than 2,500 rollouts and more than 100 hours of human labor, that each trial takes a few minutes, that it ran 50 rollouts per policy per task, and it assumes 1 minute per human reset. arXiv 2503.24278.
  • Operator wage: US median $35.53 per hour for electro-mechanical and mechatronics technologists and technicians, BLS 2025 wage data. O*NET.
  • Assumptions, all editable: 10 policy versions and 4 tasks per week; Cosmos runs at real-time speed (1x), since Reactor describes interactive frame rates but publishes no speed figure; 0.25 minutes of setup per simulated trial (load a start image and task text); 0.5 minutes for a person to grade each simulated clip (set 0 if you use an automatic success detector); one operator per robot; robot wear and depreciation left at $0; 10% of trials re-run on hardware. Policy hosting is $0 by default because many teams run their own policy; Reactor's hosted Praxis-1 is $0.030 per minute (Reactor docs).
  • If your real-robot testing is already automated: setups like AutoEval run trials, resets and scoring with almost no human (the study reports more than 99% less human supervision and about 500 trials per robot per day). For those teams, set robots per operator high (for example 20) and the labor gap mostly disappears; Cosmos still wins on speed, parallel sessions and robot wear. arXiv 2503.24278.
  • Not modeled: how well simulated results predict real ones for your task (measure this on a sample first), engineering time to set up either pipeline, and robot downtime.
