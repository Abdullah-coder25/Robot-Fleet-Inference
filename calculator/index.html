Sources and assumptions
  • Prices per session-minute (Praxis-1 $0.030, Cosmos Nano $0.102, FLUX Action $0.102, DreamZero $0.204) and the note that Robotics is in beta: Reactor robotics docs.
  • Praxis-1 on two B200s: 62 ms average for one robot; sixteen robots under a 250 ms p99; standard tier p99 under 270 ms; ~88 GB of expert weights read per call; a robot calls about every 1.6 s: Reactor, "Praxis-1 in 62 ms".
  • DreamZero served latency (median ~243 ms, p95 ~260 ms on two B200s) and task latency budgets (stacking ~147 ms, sorting ~152 ms, bowl into bin ~187 ms, insertion ~479 ms, single pick-and-place ~924 ms; simulated Franka): Reactor, "Optimizing DreamZero".
  • "<30 ms global rtt": Reactor Remote Policy API launch post, Nov 6, 2026.
  • B200 rents: median on-demand $8.19 per GPU-hour across 23 providers as of Nov 9, 2026 (getdeploying); neocloud mean ~$5.09 in Q2 2026 and AWS list $14.24 (tech-insider).
  • Memory bandwidth: B200 ~8 TB/s (the figure Reactor uses); Jetson AGX Thor 273 GB/s (TweakTown).
  • Assumptions: robots are billed only while a session is open; GPUs are held only during shift hours; robots-per-server for policies other than Praxis-1 are not published, so the default of 1 is a placeholder; the onboard figure is a lower bound from memory bandwidth alone, not a benchmark.
