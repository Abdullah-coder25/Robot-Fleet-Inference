Sources and assumptions
  • Prices per minute of session time, metered per second (Praxis-1 $0.030, Cosmos Nano $0.102, FLUX Action $0.102, DreamZero $0.204), and "Robotics is in beta": Reactor robotics docs.
  • Praxis-1 (27B) on two B200s: 62 ms per call for one robot (p99 64 ms); sixteen robots under a 250 ms p99; standard offering p99 under 270 ms; factory-tier target of an answer within 100 ms; about 88 GB of expert weights read per call (29 layers x 3.02 GB); a robot calls about every 1.6 s: Reactor, "Praxis-1".
  • DreamZero on two B200s: about 243 ms median and 262 ms p95 after optimization. Task budgets are the delay at which a task loses a quarter of its no-delay score: single pick-and-place 924 ms, insertion 479 ms, bowl into bin 187 ms, multi-object sorting 152 ms, stacking 147 ms (simulated DROID Franka in RoboLab at 15 Hz; budgets interpolated between delay steps 67 ms apart): Reactor, "Optimizing DreamZero".
  • "<30 ms global rtt": Reactor Remote Policy API launch post, Nov 6, 2026.
  • B200 rents: median on-demand $7.99 per GPU-hour across 27 providers as of Nov 17, 2026; lowest verified in-stock on-demand $5.62; AWS on-demand $14.24 (8x B200 p6-b200.48xlarge): getdeploying.
  • Memory bandwidth: B200 up to 8 TB/s (NVIDIA spec); Jetson AGX Thor up to 273 GB/s with 128 GB of memory (TweakTown).
  • Assumptions (mine, not Reactor's): the 30 ms round trip holds wherever the robot is (Reactor states it as an upper bound, and a robot far from a region will see more); the task budgets, measured on one simulated arm running DreamZero, carry over to other models and real robots; the robot keeps executing its current action chunk while the next one is computed, so the budget, not the call time, is the limit; robots are billed only while a session is open; GPUs are rented only during shift hours at public on-demand rates (Reactor's real cost is private and likely lower); every robot on a server is busy at the same time when the table says "full"; robots per server for models other than Praxis-1 is the minimum implied by Reactor's list price at the chosen GPU rent, not a published figure; latency for Cosmos and FLUX is a placeholder; the factory-tier price is a placeholder; the onboard figure is a lower bound from memory bandwidth alone, not a benchmark.
